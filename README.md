# Контроль школьных оценок — Google Таблица + Telegram-бот

Весь код живёт **внутри Google Таблицы** (Расширения → Apps Script), одним файлом `Code.gs`.
Внешнего сервера нет. Работает с сентября 2026 года, версия развёртывания 7.

## Как это работает

1. Родитель ставит оценку в колонку «Оценки» на листе предмета.
2. Оценка ниже порога (по умолчанию 4) — бот пишет в группу и просит тему и причину одним сообщением.
3. Ребёнок отвечает **реплаем на сообщение бота** — текст попадает в «Тему» и «Причину».
4. Бот сразу даёт кнопки: «Завтра / Через 3 дня / Ввести дату / Ещё не знаю».
5. За день до пересдачи — напоминание утром.
6. Вечером в день пересдачи — вопрос «Сдала?» с кнопками.
7. Не сдала или три дня нет даты — бот зовёт родителей упоминанием в группе.

Плюс: любая правка журнала уходит в группу отдельным сообщением.

## Установка с нуля

1. Таблица → **Расширения → Apps Script**. Содержимое `Code.gs` вставить в файл `Код.gs`.
2. Сохранить, обновить вкладку с таблицей — появится меню **«Оценки»**.
3. **Оценки → 1. Настроить таблицу**.
4. В листе «Настройки» вписать **только BOT_TOKEN** (от @BotFather).
5. **Оценки → 2. Сохранить секреты** — токен уедет в защищённое хранилище, в ячейке останется маска.
6. **Начать развертывание → Новое развертывание → Веб-приложение**: «Запуск от имени: я»,
   «У кого есть доступ: Все». Скопировать URL → «Настройки» → `WEBAPP_URL`.
7. **Оценки → 3. Подключить Telegram** → **4. Включить триггеры**.
8. Добавить бота в семейную группу, отправить там **`/group`**, затем **`/family`**.
   Каждый жмёт свою кнопку роли — ID запишутся сами.
9. **Оценки → 5. Проверить связь**.

Команды пишутся **латиницей**: Telegram считает командой только латинские слова после слеша.
Русские `/группа` и `/семья` в коде оставлены, но в группе не срабатывают.

## Обновление кода

1. Вставить новый `Code.gs` в редактор, сохранить (`Cmd+S`, дождаться, пока пропадёт
   надпись «Несохранённые изменения»).
2. **Начать развертывание → Управление развертываниями → карандаш → Версия: «Новая версия»
   → Развернуть**. Именно так, а не «Новое развертывание» — тогда URL не меняется
   и переподключать Telegram не нужно.
3. Если в коде появились новые параметры — **Оценки → 1. Настроить таблицу**:
   недостающие строки допишутся, заполненные останутся.

## Меню «Оценки»

| Пункт | Что делает |
|---|---|
| 1. Настроить таблицу | Создаёт листы, колонки, ссылки; дописывает новые параметры |
| 2. Сохранить секреты | Прячет токен в PropertiesService |
| 3. Подключить Telegram | Ставит webhook, сбрасывает зависшую очередь |
| 4. Включить триггеры | onEdit + утро + вечер |
| 5. Проверить связь | Тестовое сообщение в группу |
| Отключить бота (аварийно) | Снимает webhook — бот замолкает мгновенно |
| Состояние бота | Адрес, размер очереди, последняя ошибка Telegram |
| Убрать кнопки регистрации | Чистит сообщение с ролями |
| Кто зарегистрирован | Кто занял роли |
| Сбросить регистрацию | Освобождает роли |
| Обновить ссылки на листах | Перестраивает гиперссылки |

## Структура листа предмета

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| Даты | Оценки | Причина | Дата пересдачи | Результат | Тема | Статус |

- Строка 1 — «Предмет: …», строка 3 — заголовки, строка 5 — «1 Четверть» со средним баллом.
- **Оценки начинаются с 6-й строки.** Формула среднего охватывает `B6:B20`.
- Руками заполняются только A и B. Колонки C–G заполняет бот.
- Разметка взята из исходной таблицы и намеренно не переделывалась: скрипт лишь
  дописал справа «Тему» и «Статус».

## Ограничения, которые не обходятся

- **Бот не видит обычные сообщения в группе.** Только команды, реплаи на свои сообщения
  и нажатия кнопок — это privacy mode. Отключать его у @BotFather не стоит: тогда бот
  начнёт читать всю переписку семьи.
- **Бот не может написать человеку первым.** Личные сообщения дойдут только тем, кто
  хоть раз открыл с ним личный чат. Поэтому основной канал эскалации — упоминание
  в группе по числовому ID: оно работает всегда и никаких действий не требует.
- **`ContentService.createTextOutput()` в `doPost` ломает webhook.** Apps Script отвечает
  редиректом, Telegram считает это ошибкой 302 и бесконечно повторяет одно сообщение.
  Использовать только `HtmlService.createHtmlOutput()`.
- **`LockService` в `doPost` вешает пункты меню.** Меню ждёт освобождения блокировки
  и падает по таймауту через 6 минут. Защиты от дублей через кэш достаточно.
- **Простой `onEdit` не ходит в интернет** — нужен устанавливаемый триггер.
- **Максимум 15 оценок на предмет за четверть** (строки 6–20). Дальше средний балл
  перестанет их учитывать — диапазон придётся расширять вручную.

## Если что-то сломалось

1. **Оценки → Состояние бота.** Очередь и последняя ошибка Telegram. С этого начинать всегда.
2. **Журнал выполнений** в редакторе скрипта — видно, дошло ли сообщение до кода
   и не упало ли оно.
3. Проверить, что развёрнутое приложение отвечает кодом 200:
   `curl -s -o /dev/null -w '%{http_code}' -X POST -d '{}' <WEBAPP_URL>`
4. **Оценки → Отключить бота (аварийно)** — если бот сыплет сообщениями.

## Настройки

Лист «Настройки», колонка B. Заполнять руками нужно только `BOT_TOKEN` и `WEBAPP_URL`,
остальное бот проставляет сам.

Полезные переключатели:

- `MIN_GRADE` — оценка ниже этой считается проблемной (по умолчанию 4).
- `ESCALATE_DAYS` — через сколько дней без даты пересдачи звать родителей (3).
- `NOTIFY_EDITS` — писать ли в группу о каждой правке журнала (`да` / `нет`).
- `MORNING_HOUR`, `EVENING_HOUR` — часы напоминания и вечернего опроса.
