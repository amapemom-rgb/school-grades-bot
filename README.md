# Контроль школьных оценок — Google Таблица + Telegram-бот

Весь код живёт **внутри Google Таблицы** (Расширения → Apps Script), одним файлом.
Внешнего сервера нет.

## Что делает

1. Родитель ставит оценку в колонку «Оценка» на листе предмета.
2. Если оценка ниже порога (по умолчанию 4) — бот пишет в группу и просит тему + причину.
3. Ребёнок отвечает **ответом (reply) на сообщение бота** — текст падает в таблицу.
4. Бот сразу даёт кнопки по дате пересдачи: «Завтра / Через 3 дня / Ввести дату / Ещё не знаю».
5. За день до пересдачи — напоминание утром.
6. В день пересдачи вечером — вопрос «Сдала?» с кнопками.
7. Не сдала или тянет с датой → бот пишет родителям.

## Установка

1. Таблица → **Расширения → Apps Script**.
2. Содержимое `Code.gs` вставить в файл `Код.gs` (заменить всё, что там есть).
3. `appsscript.json` — через ⚙ «Настройки проекта» → галочка «Показывать файл манифеста».
4. Сохранить, обновить вкладку с таблицей. Появится меню **«Оценки»**.
5. **Оценки → 1. Настроить таблицу**.
6. В листе «Настройки» вписать **только BOT_TOKEN** (от @BotFather). Остальное заполнится само.
7. **Оценки → 2. Сохранить секреты**.
8. **Развернуть → Новое развёртывание → Веб-приложение**: «Запуск от имени: я», «Доступ: все».
   Скопировать URL → «Настройки» → `WEBAPP_URL`.
9. **Оценки → 3. Подключить Telegram** → **4. Включить триггеры**.
10. Добавить бота в семейную группу и отправить там команду **`/группа`** — бот запомнит группу.
11. Каждый (мать, отец, ребёнок) пишет боту **`/start` в личку** и жмёт кнопку со своей ролью.
12. **Оценки → 5. Проверить связь**.

## Регистрация: почему не нужен сторонний бот для ID

Числовой ID приходит вместе с каждым сообщением — Telegram присылает его боту сам.
Спрашивать ID у человека или отправлять его к @getidsbot незачем: бот его уже знает.
Неизвестна только роль — её и спрашивают три кнопки после `/start`.
Бот сам записывает ID и юзернейм в нужные строки листа «Настройки».

Роль занимается один раз. Если ошиблись — меню **Оценки → Сбросить регистрацию**,
после этого можно зарегистрироваться заново. Проверить, кто уже записан:
**Оценки → Кто зарегистрирован**.

## Важные ограничения (так устроен Telegram)

- **Писать человеку по @username бот не может** — нужен числовой `user_id`.
  В группе @username работает только как упоминание в тексте.
- **Личное сообщение придёт, только если человек писал боту `/start`.**
  Пока родитель не зарегистрировался, эскалация уходит только в группу с упоминанием.
- **Ответы ребёнка бот видит, только если это reply на сообщение бота** либо нажатие кнопки.
  Это privacy mode ботов в группах. Отключать его у @BotFather не стоит — тогда бот
  будет видеть всю переписку в группе.
- **Простой `onEdit` не умеет ходить в интернет** — поэтому нужен пункт «Включить триггеры».
- **Веб-приложение с доступом «все»** — требование Telegram к webhook.

## Структура листа предмета

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| Дата | Оценка | Тема | Причина | Дата пересдачи | Результат | Статус |

Строка 1 — ссылка «← к списку предметов», строка 2 — заголовки, данные с 3-й строки.
Руками заполняются только A и B. Колонки C–G заполняет бот:

- **C, D** — из ответа ребёнка на первый вопрос.
- **E** — из кнопки или введённой даты.
- **F** — из кнопки «Сдала / Не сдала» вечером в день пересдачи.
- **G** — состояние процесса, ставит только скрипт.
